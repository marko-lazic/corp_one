## Run the project

### Run server components

```shell
cargo run --bin corp_login
cargo run --bin corp_server
```

### Run client

```shell
cargo run --bin corp_client
```

### Run tests

```shell
cargo test
```

For more info check [tests/README.md](tests/README.md)

# Run benchmarks

```shell
cd benches
cargo bench
```
